# Understanding Mamba-3 Through Oscillatory Dynamics

Research project page by Shutian Liang and Yue Song, College of AI, Tsinghua University.

Code: https://github.com/Shutian-Liang/understandingmamba3

## Preview

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000/.

## GitHub Pages

Upload this directory’s contents to the repository root, including `.nojekyll`.
In Settings → Pages, choose Deploy from a branch → main → / (root).

## Files

- `index.html`: page content and result tables
- `assets/stylesheets/mamba.css`: layout and styles
- `assets/scripts/mamba.js`: rotation demo and result switching
- `static/mamba/`: paper figures
- `assets/papers/understanding-mamba3.pdf`: manuscript
